Jangan cuma ganti base URL

Beberapa endpoint sudah pindah kategori, jadi path lama bisa tidak berlaku lagi. Cek dulu sebelum mengubah kode.

  1. Cross-check endpointCocokkan setiap endpoint yang kamu pakai dengan kategori barunya.
  2. LoginSistem baru memakai akun, tidak lagi akses bebas tanpa login.
  3. Generate API keySetelah login, buat API key dan pakai di setiap request.
  4. Ganti base URLTerakhir, arahkan request ke domain Dinonic.
